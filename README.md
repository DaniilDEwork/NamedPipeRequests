# Обработка заявок через именованный канал

Студент: Денисенко Даниил Евгеньевич

Группа: 4п4.23 NET

Дисциплина: Асинхронное программирование в C#

## Описание

Клиент отправляет 8 заявок через именованный канал, сервер обрабатывает не больше двух одновременно и возвращает результаты

## Запуск

Нужен NET 8 SDK, команды выполняются из папки NamedPipeRequests

Сборка проекта

```powershell
dotnet build NamedPipeRequests.sln
```

Сервер в первом терминале

```powershell
dotnet run --project Server --no-build
```

Первый клиент во втором терминале

```powershell
dotnet run --project Client --no-build -- "Клиент 1"
```

Второй клиент в третьем терминале

```powershell
dotnet run --project Client --no-build -- "Клиент 2"
```

По Ctrl+C сервер завершает принятые заявки и останавливается
